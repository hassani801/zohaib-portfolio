# Portfolio — Design Agency Site

A Next.js design agency site built from a reference layout, branded as **Portfolio** with **Zohaib** as CEO.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What matches the original

- **Hero**: `HomeHeroBg.svg`, white Playfair headlines, marquee pill, review strip, platform badges, floating device mockups
- **Industries**: Cream `#FAF7F6` background, pastel cards (`#D1E9FF`, `#FBE8FF`, etc.), real web/app mockup PNGs
- **Services**: Tabbed image switcher with original JPG assets
- **Stats**: Animated counters (350+, $120M+, 45+, 500+, 98%)
- **Testimonials**: Client photos and Clutch link
- **Video**: Cloudinary compressed showreel
- **Contact**: Purple `#531fae` section, CEO block, underline form fields
- **Mobile nav**: Bottom black tab bar (Home / About / Services / Contact)

## Assets

Images are served from `/public/images` and `/public/assets` (downloaded from the live site).

## Stack

Next.js 15 · TypeScript · Tailwind CSS · Framer Motion
